# Business-Data-Analysis
End-to-end financial sales and profit analysis using Python, Pandas, Excel, and Power BI

## Project Overview
This project presents an end-to-end analysis of financial sales data to identify important business trends and insights related to sales, profit, products, countries, segments, discounts, and yearly performance.

## Tools & Technologies
- Python
- Pandas
- Excel
- Power BI
- CSV

## Project Workflow
1. Cleaned and prepared the dataset using Python and Pandas.
2. Performed Exploratory Data Analysis (EDA).
3. Analyzed business metrics using Pandas and Excel.
4. Created PivotTables and charts in Excel.
5. Developed an interactive dashboard using Power BI.
6. Identified key business insights and recommendations.

## Dataset
- 700 rows
- 16 columns
- Financial sales and profit data
- Includes product, country, segment, discount, sales, profit, and date information.

## Key Insights
- Paseo recorded the highest sales and profit among the products.
- Carretera recorded the lowest sales and profit among the products.
- 2014 had higher sales and profit than 2013.
- Medium Discount Band had the highest sales.
- Low Discount Band had the highest profit.
- High Discount Band had the highest total discount amount.

## Deliverables
- `cleaned_data.csv` — Cleaned dataset
- `data_analysis.ipynb` — Python/Pandas analysis
- `Financial_Data_Analysis.xlsx` — Excel analysis and charts
